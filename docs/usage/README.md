# 利用ガイド

本ドキュメントは、ssmm の導入、EC2 の検索、Session Manager 接続、SSH 接続、ファイル転送に必要な操作を案内する。

## 用語

本ガイドで使う用語を、以下にまとめる。

| 用語 | 意味 |
| --- | --- |
| TARGET | EC2 の Name タグの値、またはインスタンス ID |
| Name | EC2 のタグキー `Name` に設定された値 |
| ssmm プロファイル | 検索範囲、使用する AWS プロファイル名、SSH の既定値をまとめた設定。`-s` で選択する |
| AWS プロファイル | AWS 認証設定の名前。`-p`、ssmm 設定の `aws_profile`、`AWS_PROFILE` で指定する |
| 検索範囲 | 1 回の実行で EC2 を取得するリージョンの集合 |
| 候補 | TARGET、タグ、部分一致フィルタに一致した EC2 インスタンス |
| 操作端末 | 対話選択のために開く `/dev/tty`。標準入力・標準出力のリダイレクトとは別に判定する |
| SSH 連携 | `NAME.PROFILE.ssmm` 形式のホスト名を標準の `ssh`・`scp` で使うための設定 |

## 対象範囲

商用 AWS の EC2 インスタンスを対象とする。AWS China、AWS GovCloud、`mi-` で始まるハイブリッドノードは対象外である。ローカル実行環境は Unix を前提とし、Windows ネイティブ向けの端末処理と設定ロックは実装していない。

ssmm はインスタンスの起動、SSM Agent の導入、IAM 権限の付与、SSH 鍵の登録を行わない。
